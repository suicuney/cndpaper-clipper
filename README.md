# cndpaper 网页裁剪

`cndpaper 网页裁剪` 是一款轻量、专注于单一任务的 Chrome / Edge 浏览器扩展 (Manifest V3)。它能够帮助你一键提取当前网页的正文内容，转换为清晰规范的 Markdown 格式，并按本机日期自动归档保存到指定的本地目录中。

---

## 🌟 核心功能

- **正文智能提取**：基于 Defuddle 算法解析网页正文，自动过滤广告、导航栏与无关杂质。
- **日期自动归档**：按保存时的本机日期自动新建日期文件夹（例如 `2026-08-05/`），方便检索与整理。
- **同名自动防覆盖**：当遇到同名文件时，系统会自动追加序号（如 `网页标题-2.md`），确保历史数据不丢失。
- **纯本地与隐私安全**：
  - 网页解析与格式转换完全在浏览器本地完成。
  - 仅写入用户主动选择并授权的本地目录（基于 File System Access API）。
  - 无任何外部模型调用、数据上报或云端同步。

---

## 📂 存储结构示例

首次使用时，在扩展面板中选择一个授权目录。后续点击保存时，文件将按如下目录结构归档：

```text
你授权的本地目录/
├── 2026-08-03/
│   ├── 网页标题.md
│   └── 网页标题-2.md
└── 2026-08-05/
    └── 深度好文解析.md
```

## 🚀 安装与开发

### 1. 构建扩展

确保已安装 [Node.js](https://nodejs.org/) 环境，在项目根目录下执行：

```bash
# 安装依赖
npm install

# 生产环境打包（生成 dist/ 目录及 zip 压缩包）
npm run build
```

### 2. 在浏览器中加载

1. 打开 Chrome 或 Edge 浏览器，访问 `chrome://extensions`（Edge 访问 `edge://extensions`）。
2. 在右上角开启 **“开发者模式”**。
3. 点击 **“加载已解压的扩展程序”**。
4. 选择本项目打包生成的 `dist` 目录即可完成安装。
